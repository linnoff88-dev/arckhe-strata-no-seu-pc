Local AI · free INEMA kit

You pay for an AI subscription and send your files elsewhere. Run a large AI model on your PC with Strata and the counter and pantry method.

You’re running into usage limits and want to keep your files on your PC. Strata runs AI locally and connects your tools. Minimum: 32 GB of RAM with a compatible 12 GB graphics card, with limitations; 48–64 GB of RAM for the main packages and an SSD with free space.

Understand the methodView on GitHub
In brief

You want to use AI without paying for every question and keep your files on your computer. Strata is a free, open-source engine that splits a large AI model across your graphics card, memory, and storage. This kit helps you choose a size and connect your tools, based on the official documentation. You need compatible hardware, memory, and space for the model; if you have Windows or Mac and just want to chat, you can use the app and skip the technical section.

Counter and pantry

MoE (mixture of experts) is a team of specialized parts of the model. Qwen3.8 has 24,576 experts and uses 10 per word, according to the documentation.

Counter: graphics card

VRAM (graphics card memory) holds the most-used experts and handles the common part of each word. In this method, more VRAM matters more than a faster card.

Pantry: RAM

RAM (computer memory) holds the experts. The processor works on the ones that do not fit on the card, at the same time as the card does.

Basement: SSD

The SSD holds the lookup table. If RAM runs short, it also supplies experts, much more slowly. NVMe (a fast SSD interface) matters when the drive does a lot of the work.

Guess and check

A small helper suggests the next words. The large model checks them and accepts only what it approves. The documentation describes the same quality with less waiting.

Source: HOW_IT_WORKS.md and MODELS.md in docs-oficiais/.

What fits on your PC

Choose based on the detected RAM. The sum of RAM + VRAM is only a reference; unified memory is counted once. The ranges are contiguous: 30–45.9 means 30 ≤ RAM < 46, including readings such as 45.99. These are conservative kit groupings, not new official requirements.

Q2_0, IQ2_XS, IQ3_S, UD-Q4_K_XL, NVFP4 are compression levels of the same model: fewer bits = less memory and slightly lower quality. ISTA-DASLab and Unsloth are groups that prepare these packages.

bpw means bits per weight (how many bits store each model parameter). mmap maps a file into memory and lets you read parts of it as needed. WSL is Linux inside Windows. CLI is the command-line interface, used by the terminal. JSON is a data format with names and values. Endpoint is a server address that receives a type of request.

In the range of 62–93.9 GB of RAM with a separate GPU, all four packages are options: Q2_0 is the fastest. With 62.5 GB read, the remaining amounts are Q2_0: 18.5 GB; IQ2_XS: 17 GB; IQ3_XXS: 9.5 GB; IQ3_S: 2.5 GB. The calculation reserves 10 GB for the system. The docs say that with 64 GB of RAM they all fit, IQ3_S with very few things open.

Estimated remaining memory: read RAM − experts − 10 GB. Experts: Q2_0 34; IQ2_XS 35.5; IQ3_XXS 43; IQ3_S 50; Coder 23; Unsloth UD-IQ4_XS 72, UD-Q4_K_XL 88, UD-Q5_K_XL 108 and UD-Q6_K_XL 118 GB. Remaining memory from 0 to less than 3 GB: “fits tightly”; negative: “does not fit in normal mode; low-memory mode only”. In the 30–45.9 range, a compatible GPU with at least 12 GB is required; Coder uses little RAM and the SSD, with a speed penalty. For Gyro-S, the docs give only combined memory: reference remaining memory = RAM + VRAM − 27.6 − 10 GB; this does not confirm how memory is divided between the two.

Unified memory: the same ranges, without adding VRAM. Mac requires Apple Silicon and macOS 15+; check the package in the plan. Spark options apply only to the documented DGX Spark with 128 GB nominal memory, even if the system reads 125 GB. Other ARM systems are unconfirmed. On Spark, NVFP4 uses a 68 GB expert file with mmap: RAM − 68 − 10 is only a reference, because context, cache and table also compete for memory. Q2_0 and Gyro do not run on Spark.

Disk: Q2_0, IQ2_XS and IQ3_XXS have a combined download range of 66–76 GB; the script compares against 76 GB. IQ3_S: 84 GB is a DGX Spark reference, not a universal figure for x86; confirm with --plan after installing. Gyro-S: 58.5 GB. Coder: ~58.6 GB, kit estimate (29.6 + ~29). Unsloth: 94/111/158/169 GB in the order listed; NVFP4: 128 GB. Reserve extra space for auxiliary files and preparation. IQ3_S requires few things to be open; Q8_0 is not included in the automatic list: ~136 GB for experts alone.

Best use: your tools for free

Here, “for free” means no per-token charge for the local engine. It does not promise that every feature in connected programs is free. The server communicates through an API (an interface between programs) compatible with OpenAI and Anthropic. You can connect Claude Code, Codex CLI, OpenCode, and others to the local model.

No charge per question

The local engine does not charge per token. You still pay for electricity; connected tools have their own terms of use.

Data stays at home

Conversations with the local model stay on the PC. Searches, pages, and external services you choose may send data elsewhere.

Protect the key

When opening the server to other devices, keep the access key. Connected tools have their own network rules.

Where it still falls short

  • With little RAM, more experts are served from the SSD and responses become much slower.
  • There is no app for Linux ARM64; the documented route is the terminal on DGX Spark. Do not generalize this to every ARM device.
  • Q2_0 and Gyro do not run on Spark: these kernels (optimized calculation routines) are x86-only (the common processor family in Intel/AMD PCs).
  • You need to download large files: the smallest original packages download 66–76 GB, plus auxiliary files; Unsloth reaches 188 GB. Q2_0's 37,6 GB is memory, not download size.
  • It is a new project. Hardware, package, and context affect the result; the security documentation says it has not yet had an external audit.

Sources: MODELS.md, DGX_SPARK_LINUX.md, SAFETY.md, and FATOS.md.

From choosing a size to your first conversation

Before downloading anything, consult “What fits on your PC” and the “Before installing” checklist. Check memory, disk space, and compatible hardware; if you need the script, do step 2 first. The app and terminal routes are alternatives. These are documented commands for you to run if and when you decide to install. We did not run anything from Strata. Sources: INSTALL.md, TERMINAL_LAUNCH.md, and DGX_SPARK_LINUX.md.

1

Only want to chat on Windows/Linux/Mac? Download the app

First, check the size in the table (step 2).

Open the official release and choose the installer for your system. In the documented version, Windows uses Strata-0.2.13-windows-x64-setup.exe; Mac uses Strata-0.2.13-macos-arm64.dmg. The filename changes with each version. strata-engine files are components, not installers. Mac: Apple Silicon and macOS 15 or newer; open the .dmg and drag Strata to Applications. After checking the size, install and choose the engine and model. Wait for preparation, open the app chat, and send your question. The response should appear in the conversation; if there is an error, see the tips below. You can skip the terminal commands.

Linux x86-64 uses .AppImage. A release is a published version available to download.

Linux: in the download folder, make the AppImage executable and open it (INSTALL.md; adjust the name to match the downloaded version):

chmod +x Strata-0.2.13-linux-x86_64.AppImage
./Strata-0.2.13-linux-x86_64.AppImage
2

Find out what size fits

Compare your memory with the size table above before any download.

Download the kit ZIP, extract it, and open the folder in a terminal (a window for entering commands). If you already have Bash (a program that interprets terminal commands), run:

QT_LANG=en bash ferramentas/qual_tamanho.sh

The script uses Bash; translated output with QT_LANG=en or QT_LANG=es also requires Python 3 to be installed. Without QT_LANG, the default is Portuguese.

Windows without Bash: open Task Manager (Ctrl+Shift+Esc) > Performance > Memory for RAM; GPU > Dedicated GPU memory for the card; Disk to identify storage. Settings > System > About also shows RAM. For free space, open File Explorer > This PC and check the destination drive. Compare with the table before downloading.

On Linux/Mac/WSL, use the script above. It compares free space in the current folder with the suggested download, but extra files and preparation need more space. It installs nothing and does not detect AMD/Intel VRAM.

With 32 GB RAM and a 12–16 GB graphics card: Gyro-S for general use (27.6 GB RAM + VRAM; 58.5 GB download), or Coder for coding in low-RAM mode. A 16 GB card brings the total to 48 GB, but RAM remains 32 GB.

3

Install from the terminal

Linux/Mac: curl saves install.sh in the current folder; then sh runs that file.

curl -fsSL --connect-timeout 15 --max-time 120 https://github.com/Niko1221/Strata/releases/latest/download/install.sh -o install.sh && sh install.sh

Windows PowerShell:

irm -TimeoutSec 120 https://github.com/Niko1221/Strata/releases/latest/download/install.ps1 | iex

After installing Strata and opening a new terminal, check the plan before downloading the model. Choose only the command for the compatible option in the table; --plan shows the plan without starting the model. Do not change only the size while keeping the qwen family: Coder, Gyro, Unsloth, and NVFP4 have their own families. For IQ3_S on x86, confirm the download for your platform here.

strata launch --plan --family gyro --model Gyro-S
strata launch --plan --family coder --model IQ1_M
strata launch --plan --family qwen --model Q2_0
strata launch --plan --family qwen --model IQ2_XS
strata launch --plan --family qwen --model IQ3_XXS
strata launch --plan --family qwen --model IQ3_S
strata launch --plan --family unsloth --model UD-IQ4_XS
strata launch --plan --family unsloth --model UD-Q4_K_XL
strata launch --plan --family unsloth --model UD-Q5_K_XL
strata launch --plan --family unsloth --model UD-Q6_K_XL
strata launch --plan --family nvfp4 --model NVFP4

Open a new PowerShell after installing. On Linux/Mac, the installer prints the command path (usually ~/.local/bin/strata); use that path if the command is not found. The documentation does not specify a final success message. Then choose a model, folder, context, and access:

strata launch

PowerShell is the Windows command terminal: open Start, type PowerShell, and open the app.

To check that it worked, see the address and the running model (TROUBLESHOOTING.md and AI_SETUP.md):

strata launch --status
strata doctor --live

Linux/Mac, on the default port:

curl -fsS http://127.0.0.1:8080/health
curl -fsS http://127.0.0.1:8080/v1/models

PowerShell:

Invoke-RestMethod http://127.0.0.1:8080/health
Invoke-RestMethod http://127.0.0.1:8080/v1/models

Use the address reported by launch and the credential configured for protected endpoints. Confirm the loaded model and send a question, or use the tool check in step 4. Exit code 0 alone does not prove that the server started.

4

Connect your tools

Install Node.js with npm from https://nodejs.org. Check both versions before installing the CLIs:

node -v
npm -v

strata connect claude-code and strata connect codex show the masked key by default. Before copying ANTHROPIC_AUTH_TOKEN or STRATA_API_KEY, use strata connect claude-code --show-key or strata connect codex --show-key, respectively; another option is strata launch --show-key. Copy the real key, not the mask.

npm i -g @anthropic-ai/claude-code
npm i -g @openai/codex

Get the local key with strata launch --show-key or on the launch Connect screen (press k to reveal it), as described in TERMINAL_LAUNCH.md. Replace STRATA_KEY with the displayed value. Before using Codex, set the variable in this same window:

Linux/Mac:

export STRATA_API_KEY="STRATA_KEY"

PowerShell:

$env:STRATA_API_KEY="STRATA_KEY"

Claude Code and Codex CLI are coding assistants in the terminal. The monitor is the status screen that strata launch opens in the terminal. Press q and choose to keep the server running in the background. A prompt is the text request sent to the model.

strata connect claude-code (alternative name: claude) shows what goes into ~/.claude/settings.json; --write saves it with a backup of the existing file; --check checks the connection. It sets ANTHROPIC_BASE_URL (address without /v1), ANTHROPIC_AUTH_TOKEN (your Strata key; no Anthropic account is used), model, CLAUDE_CODE_MAX_CONTEXT_TOKENS and CLAUDE_CODE_MAX_OUTPUT_TOKENS. Then use claude -p "your task" or claude. The [claude-code:unrecognized_model] notice is harmless.

strata connect codex shows the configuration; --write saves ~/.codex/config.toml with a backup. Set STRATA_API_KEY in the terminal to your Strata key, following the generated instructions (it is not an OpenAI key). The variable is required; if the server has no key, any text works. The "Model metadata ... not found" notice is harmless.

For users of Claude Code through the subscription: --write changes the global file ~/.claude/settings.json; Claude Code then uses Strata and stops using the subscription for those calls. To preserve the global configuration, open a separate terminal and run strata connect claude-code without --write. Copy all the variables it prints (address, key, models and limits) and export them only in that terminal. The examples below are templates: replace ... with the printed values. Then open claude in that same terminal. To return to the subscription, close that terminal.

DGX Spark

Use the same Linux installer and strata launch. The package requires glibc (Linux library) 2.39+ and NVIDIA driver (software that controls the card) 580.65+. Choose IQ3_S, NVFP4, or DeepSeek 2.00 bpw; not Q2_0 or Gyro. There is no ARM app.

DGX Spark is a compact NVIDIA computer with 128 GB of unified memory.

20 tips to refer to

Before installing

1. Add without double-counting

Add RAM (computer memory) and VRAM (graphics card memory). On Mac and other systems with unified memory, count it once. The total is only an initial screening; leave room for the system.

Source: MODELS.md (docs-oficiais/).

2. Check free disk space

Download size is not RAM use: the smallest original packages download 66–76 GB, plus auxiliary files. Choose a folder with room for the download and preparation.

Source: MODELS.md; INSTALL.md (docs-oficiais/).

3. Prefer an SSD and check NVMe

SSD is fast storage; NVMe is an SSD interface. If RAM cannot hold all the experts, fetching them from disk makes responses much slower; for DeepSeek, the documentation calls for NVMe.

Source: MODELS.md (docs-oficiais/).

Choosing a size

4. Choose the largest size that fits comfortably

Use TABELA.en.md and check RAM separately from VRAM. Context and open apps also use memory; the largest available file may be a poor choice for your PC.

Source: MODELS.md (docs-oficiais/).

5. Coder is for programming

Less memory, general use: compare Unsloth, then Gyro. On a PC with 32 GB RAM + a 12–16 GB card, consider Gyro-S; for coding, Coder. Both are slower alternatives. (Gyro: a compression method that uses less memory and is slower).

Source: MODELS.md (docs-oficiais/).

6. Low RAM shifts work to the SSD

With 32 GB RAM and a 24 GB graphics card, the documentation describes Q2_0, IQ2_XS, and Coder in low-RAM mode. With a 12–16 GB card, it describes Coder; strata launch has no --low-ram flag.

Source: MODELS.md (docs-oficiais/).

7. ISTA-DASLab first; Unsloth next

The documentation recommends starting with a compatible ISTA-DASLab package that fits. Unsloth stores more bits and needs more RAM: UD-IQ4_XS downloads 94 GB and needs ~72 GB of RAM for all experts.

Source: MODELS.md (docs-oficiais/).

8. Pitfall: “any 8 GB graphics card can run the 94 GB model”

The graphics card alone does not decide. The 94 GB is the UD-IQ4_XS download size; the documentation calls for ~72 GB of RAM to keep its experts, and less RAM can push work to the SSD.

Source: MODELS.md (docs-oficiais/).

9. Pitfall: “faster means a faster graphics card”

The documentation says more VRAM matters more than a faster GPU in this method. The card holds the most-used experts; having more of them there reduces the processor's workload.

Source: HOW_IT_WORKS.md (docs-oficiais/).

Installing

10. Pitfall: “it's just a script and you're done”

Choose the app or terminal route, then choose a model and size. The terminal uses install.sh or install.ps1 and strata launch; downloading the installer does not mean the model is ready.

Source: INSTALL.md (docs-oficiais/).

11. Choose the route for your system

There is an app for Windows, Linux x86-64, and Apple Silicon Mac. Mac requires macOS 15 or newer; Intel Arc uses the terminal on Linux, and the Mac package does not support Intel Mac.

Source: INSTALL.md (docs-oficiais/).

12. DGX Spark uses the terminal

There is no app on Linux ARM64. The project documents IQ3_S, NVFP4, and DeepSeek 2.00 bpw on Spark; Q2_0 and Gyro have x86-only kernels and do not run there.

Source: DGX_SPARK_LINUX.md (docs-oficiais/).

13. The engine does not replace the driver

CUDA 13 packages (NVIDIA's computing platform) require NVIDIA driver 580 or newer; on Spark, 580.65 or newer. Older NVIDIA cards use the CUDA 12 route; check the documentation before choosing a package.

Source: INSTALL.md; OLDER_GPUS.md; DGX_SPARK_LINUX.md (docs-oficiais/).

Connecting tools

14. Get the ready-made configuration

strata connect lists Claude Code, Codex CLI, OpenCode, and others. The default local address is http://127.0.0.1:8080; use the address Strata shows for your server.

Source: TERMINAL_LAUNCH.md (docs-oficiais/).

15. Save with a backup and check

strata connect opencode --write asks before saving and backs up what it replaces. strata connect opencode --check sends a prompt and a tool call; this is a check you can run.

Source: TERMINAL_LAUNCH.md (docs-oficiais/).

16. Keep the key when connecting from outside the computer

To start, leave access set to local.

  • local: this PC only.
  • lan: devices on your network; keep the key.
  • tailscale: your Tailscale network; it must be installed and connected.
  • cloudflare: an internet tunnel; requires cloudflared and a key.

Source: TERMINAL_LAUNCH.md; SAFETY.md (docs-oficiais/).

Privacy

17. No telemetry does not mean no connections at all

The documentation says there is no usage data, analytics, or error reports sent. Installs and updates access the network; searches, pages, tunnels, external services, and tool servers may also access it.

Source: SAFETY.md (docs-oficiais/).

18. Tools have their own rules

Local conversations stay on the PC, but an external model receives the conversation when you choose one. Claude Code and Codex are separate programs: Strata does not control what they send.

Source: SAFETY.md (docs-oficiais/).

When something goes wrong

19. Fix the path, download, and driver

Command not found: open a new PowerShell or use the installer path on Linux/Mac. Download stopped: repeat the action and check disk space; completed steps are reused. Old driver: update according to the package and restart if needed.

Source: TROUBLESHOOTING.md (docs-oficiais/).

20. Fix slowdowns and a busy port

Slow first launch: check the log, close programs, and reduce the model/context if memory runs short. Port in use: check strata launch --status; --restart interrupts current responses. Do not stop an unrelated program just because it is using the port.

Source: TROUBLESHOOTING.md (docs-oficiais/).

The last tips cover five problems for reference. The documentation does not provide a ranking of the most common ones.
